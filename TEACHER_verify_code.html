Verify a high-score code

Paste the student's name and the code from their screenshot. This recomputes the code and tells you if it matches. It catches casual photo-editing; it is not cryptographically secure.

How the code works

The code has the form RDR-[flag]-[score]-[hash].

  • flag: two letters. First is H (hard mode) or N (normal). Second is C (full campaign run) or S (single level).
  • score: the points total, written in base-36 (so it looks scrambled). This tool decodes it back to a normal number.
  • hash: a fingerprint of name + score + flag. Change any of them and the hash no longer matches.

A valid HC code means the student earned that score in hard mode across a full campaign run — the highest-value combination.
