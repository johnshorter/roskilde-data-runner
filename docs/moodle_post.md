# Suggested Moodle post


**🏆 Roskilde Data Runner — a game for the whole course**

Want to test how much of Basic Course 1 has stuck? Download the game below, unzip it, and open **Roskilde_Data_Runner.html** in your browser (no installation needed — it even works offline).

Ten quick levels, one for each lecture: sorting data types, Python and messy CSVs, choosing the right graph, centre and spread, fitting a line, sampling, probability and dice, the binomial, the normal curve and confidence intervals, and a final "mini-project" round. Type your name, pick a level, and play.

Chasing a high score? Try **Campaign mode** (all levels in one run, +50% bonus) and **Hard mode** (faster, double points). When you finish, screenshot your score card — the one with the code on it — and send it to me. The top scores win a small prize. 🥇

The game is in English.
